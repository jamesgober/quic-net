# quic-net v0.2.0 - The wire layer

**QUIC's wire format, read and written without I/O or TLS.** Packet headers, version negotiation, every transport frame, transport parameters, and connection IDs with stateless reset tokens, each decoder fuzzed and bounded.

```rust
use quic_net::{Frame, PacketKind, frames, parse_packet};

let packet = parse_packet(&datagram, 8)?;
// ... remove header and packet protection, then:
for frame in frames(&payload, PacketKind::OneRtt) {
    match frame? {
        Frame::Stream { stream_id, data, .. } => { /* ... */ }
        _ => {}
    }
}
```

## What is quic-net?

QUIC (RFC 9000) for Rust, built up from its parts on net-io's UDP socket and tls-net's TLS 1.3. This release is the layer that needs neither.

## What's in 0.2.0

- **Variable-length integers** (RFC 9000 section 16).
- **Packet headers** read before header protection is removed: long headers (Initial, 0-RTT, Handshake, Retry), short headers, version negotiation, and other versions reported so a server can negotiate. A datagram's coalesced packets are split (at most 8). Packet numbers encode and decode as in appendix A.
- **All 21 transport frame types** of version 1, decoded without copying and written back.
  - Checked: frame types on the fewest bytes, ACK ranges that never go below zero (at most 256), offsets and stream counts within their limits, and the frames each packet type may carry.
- **Transport parameters**, with each one's range and the side allowed to send it.
- **Connection IDs** both ways, within the advertised limits, and **stateless reset tokens** derived from a secret key with keyed BLAKE3 and compared in constant time.

## Costs

Measured on Linux at a load average of about 10, so upper bounds:

| Path | Cost |
|---|---|
| parse a short header | 9 ns |
| read an ACK and a 1,100-byte STREAM frame | 31 ns |
| decode transport parameters | 39 ns |

## Known gaps

- No packet protection, handshake, or streams yet. They need tls-net's QUIC interface, which `dev/PLAN.md` section 5 describes.
- net-io's UDP lacks GSO, GRO, ECN, and the don't-fragment bit (also section 5).

## What's next

`0.3.0`: the connection API, and packet and header protection on tls-net's QUIC interface.
